# 词伴代码生成任务清单

本清单与《英语学习平台项目企划书与开发规格》1.0 配套使用。文档中的技术选型是开发基线，不代表已创建代码、已接入供应商或已完成测试。先完成 W0 验证再锁定具体依赖版本。

## 每轮固定输入与输出

输入：企划书、当前仓库、前轮验收结果、任务包 ID。输出：可运行代码、运行命令、更新后的 schema 与函数/UI 注册表、必要测试、验收证据、尚存限制。禁止只输出计划或空页面代替本轮实现。

所有手写函数采用企划书第16节模板；公共函数还登记 registry。模板 JSON 是注册表结构的 JSON Schema，不能直接把 schema 文件当业务函数清单。ID 跨版本稳定且全仓唯一，唯一性需 CI 额外检查。

## G0 平台能力验证

任务：建立可丢弃样机，验证 Android 容器真机音频、后台恢复、SQLite 持久化、文件导入、通知、录音以及 Web 离线。测试存储失败、系统杀进程、拒绝权限与弱网。记录设备、系统、浏览器和插件版本，形成技术 ADR。通过后选定容器方案；否则采用原生 Android 备用方案。

完成标准：每项有实测结果与降级策略，不能只凭库文档认定支持。依赖未确认时不开始大规模 UI。

## G1 本地学习纵向切片

任务：初始化单仓与 CI；实现游客档案、固定测试词包、一张卡完整作答与评分；注入 Clock、IdGenerator、LocalStore；在一个事务中写 ReviewEvent、ReviewState、outbox；应用重启能恢复。

关联：CARD-CREATE-001、LEARN-REVIEW-001、LEARN-SCHEDULE-001。验收：AT-07、AT-08、AT-28。测试词包必须写明测试来源，不伪装成正式词书。

## G2 身份与最小同步

任务：实现会话、访问授权、push 逐项 ack、pull cursor、快照、事件去重和确定性归并；完成游客合并预览。先实现两设备同一学习项目离线并发，不把简单最后写入覆盖称为同步。

关联：SYNC-PUSH-001、SYNC-PULL-001、SYNC-MERGE-001。验收：AT-10、AT-11、AT-12、AT-13、AT-22。生产错误注入测试覆盖断网、响应丢失、401、409、429 与存储失败。

## G3 词库 卡片 List 与导入

任务：公共与个人卡、义项、关联、词书引用、普通和收藏 List、关键词查词、TXT/CSV/JSON 导入预览与错误行、导出。完整实现去重范围与删除语义。

关联：CARD-VALIDATE-001、CARD-LINK-001、LIST-CREATE-001、LIST-REMOVE-001、IMPORT-PARSE-001、IMPORT-COMMIT-001、SEARCH-LOOKUP-001。验收：AT-04 至 AT-06、AT-18、AT-23。

## G4 离线包与网络门禁

任务：NetworkPolicyGate、三种网络策略、下载 manifest、临时下载与校验、原子激活、缓存清理边界、浏览器配额提示。任何 Repository 的远端出口都受策略约束，不能只禁止 AI。

关联：NETWORK-GATE-001、MEDIA-PACKAGE-001。验收：AT-09、AT-14、AT-15。用网络记录证明确实未产生被禁止的请求。

## G5 双模式与学习界面

任务：清爽与完整布局、组件注册、已发布模块开关、作答状态机、每日预算、复习单、List 单、时区与凌晨四点日界、可访问性。模式切换和应用恢复保持当前会话。

关联：PROFILE-MODE-001、LEARN-QUEUE-001、LEARN-UNDO-001。验收：AT-01、AT-29、AT-30；所有页面满足适用异常态。

## G6 测评与目标

任务：自报目标、跳过测评、版本化题库、快速和完整测评、适应式内部 band、四维报告、缺测和可信度说明、目标词书建议。

关联：PROFILE-GOAL-001、ASSESS-NEXT-001、ASSESS-SCORE-001。验收：AT-02、AT-03；报告不得给出未经标定的考试分数和精确词汇量。

## G7 基础听力

任务：文本和音频私有导入、已有时间轴读取、整段与按句播放、AB 循环、倍率、译文开关、断点续听、选词选句制卡、离线包。P0 未接对齐服务时允许手动时间轴，不生成假时间戳。

关联：LISTEN-LOOP-001、LISTEN-CARD-001。验收：AT-16、AT-17、AT-21，飞行模式和实际 Android 设备均验证。

## G8 P0 发布加固

任务：授权检查、安全输入、数据导出删除、日志脱敏、备份恢复、迁移回滚、性能基准、Android 安装包与 Web 部署说明。邀请用户试用并收集学习效果基线。

验收：所有 P0 对应 AT 通过，发布前未完成的 P1/P2/P3 入口隐藏。列出已知限制，不以“待优化”掩盖数据丢失和越权。

## G9 AI 能力 P1

任务：服务端 ProviderAdapter、预算预占与结算、异步任务、翻译解释、TTS/ASR/对齐、语义检索、过期结果保护和取消。随后交付 AI 文字房，稳定后接语音。

关联：AI-JOB-001、AI-APPLY-001、CORPUS-COUNT-001。验收：AT-19、AT-20；给出单次任务成本与真实失败降级。

## G10 工具与应用内宠物 P1

任务：可恢复番茄钟、提醒安静时段、灵感转卡、宠物事件与对白、声明式动作、减少动效设置。系统级悬浮宠物继续后置。

关联：FOCUS-RESTORE-001、PET-EVENT-001。验收：AT-21、AT-30；拒绝通知权限不影响学习。

## G11 真人主题房与社区 P2

任务：先完成审核台、举报、屏蔽、申诉和邀请机制，再接公开内容与房间。SFU 媒体令牌、成员角色、断线恢复、推荐规则和去刷量由服务端决定。

关联：ROOM-JOIN-001、COMMUNITY-RANK-001、MODERATION-ACT-001。验收：AT-22、AT-24、AT-25；没有运营审核能力时不开放公开社区。

## G12 经营与扩展 P3

任务：确认上线地区和渠道后接支付、签名回调、退款状态、账本、广告举报和收支摘要。随后逐项验证游戏房、系统悬浮宠物、受限 MCP 扩展。

关联：BILLING-CALLBACK-001。验收：AT-26；读写工具范围、用户确认和审计完成后再开放外部调用。

## 每轮验收报告格式

```text
任务包 ID
实现的功能 ID 和页面 ID
本轮代码与数据迁移
启动和验证命令
对应 AT 编号与实际结果
真实设备和依赖版本
失败路径与降级证据
尚未完成内容和已知限制
下一轮输入
```
