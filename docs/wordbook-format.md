# 批量词书格式

导入入口只接受 UTF-8 的 `.csv`、`.txt`、`.json`。文件大小不超过 10 MiB，最多 10,000 条。CSV 使用逗号分隔，TXT 使用制表符分隔；JSON 必须是 `{ "schemaVersion": 1, "title": "...", "cards": [] }`。

表头必须从下列列开始并保持顺序：

`kind,text,translation,partOfSpeech,pronunciation,definition,example,exampleTranslation,category`

前三列必填。`kind` 只能是 `word` 或 `sentence`，其余列可留空。CSV 的逗号、引号和换行遵循 RFC 4180 双引号转义规则。导入会先解析、校验、显示前 20 条预览，重复项按 `kind + text` 去重；错误行不会被静默转换成“待补充译文”。用户必须确认后才写入本地存储。

错误列表中的“行”表示去掉空白记录后的逻辑记录序号，CSV/TXT 包含表头，JSON 表示 cards 数组第几项；带引号的多行字段仍视为一条记录。原文会折叠连续空白、忽略首尾空白，重复判断不区分英文大小写。单个字段最多 5000 字符，CSV/TXT 每条记录必须与表头列数一致。

缺失必填值或列数错误可选择修复文件后重试，也可明确勾选“只导入有效记录”；文件超限、编码错误、表头错误、引号不匹配时整份拒绝。预览前不会写入卡片；保存失败也不会显示成功。JSON 中的来源声明不会被信任，普通导入卡统一标记“用户导入”，不能通过上传文件冒充 Oxford 词条。示例模板中的内容为演示内容。
