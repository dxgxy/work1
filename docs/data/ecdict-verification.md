# ECDICT 接入验证

- 已固定来源版本并保存完整上游 MIT 许可，生成 8,512 个真实有中文释义的词条；自动检查输入、输出哈希与分类数量。
- Vitest 6 文件、18 项通过，包含旧档案两次初始化不重复、复习状态保留、内置词库文本不重复写入存储、再次刷新恢复全部词条与队列关联。
- TypeScript 与生产构建通过。随应用打包的词库使 JS 约 2.6 MB，构建工具会提示大文件；页面用 48 条分页控制 DOM 数量。
- Playwright MCP 实测：真实词库总数、四级分类 3,846、下一页、adapt 单词与中文释义、生产版资源缓存后断网刷新，全部通过。浏览器控制台 0 错误、0 警告。
- 修复 React 在 window load 后挂载时漏掉 service worker 注册的问题。移除远程 Google Fonts，避免离线查看卡片时请求字体网络。
- 文字离线不意味着 Google 扩展发音离线；本轮未验证真实发声。ECDICT 的历史考试标签和词频不代表现行考试大纲，释义没有人工逐条校对。

浏览器证据位于 `output/playwright/library-smoke.json`，页面截图位于 `output/playwright/ecdict-search.png`。验证地址 `http://127.0.0.1:4174/` 为本机生产预览；原开发地址仍为 `http://127.0.0.1:4173/`。
