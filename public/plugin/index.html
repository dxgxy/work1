WHY IT WORKS

只做三件清楚的事

插件在用户点击后读取当前页面，给出缩略图清单，并把选中的地址交给浏览器下载。

扫描当前页面

识别 img 和 CSS 背景图，去重后最多展示 100 张。

批量勾选

默认全选，也可以取消单张图片，下载任务按序提交。

本地保存

使用 Chrome downloads API 写入本地目录，不上传图片。

INSTALL IN TWO STEPS

两分钟完成安装

01 · 下载并解压

点击上方下载按钮，解压 ZIP 文件，保留其中的 image-downloader 文件夹。

02 · 加载扩展

打开 chrome://extensions，开启开发者模式，选择“加载已解压的扩展程序”。
